设计提取设置

插件默认走本地规则路径，不联网也能产出一份完整的 DESIGN.md。 打开下方开关后改走 LLM skill 路径，由模型参与提取与语义补充。

关于两条提取路径

本地规则路径不调用任何模型，速度最快、结果稳定，适合只需要设计 token 和组件参数的场景。 LLM skill 路径在规则结果之上叠加模型判断，用于补充风格综述、颜色语义、组件描述和提示词示例。 开关可以随时切，不需要重新配置 Key。

关于存储

Key 存在本机的插件存储里（chrome.storage.local），不上传、不参与同步。 它没有加密，任何能读到这个浏览器配置文件目录的人都能看到它。不放心的话， 去服务商控制台单独建一把只用于这个插件的 Key，用完随时撤销。

网络权限按域名单独申请，只在你填了哪个地址时才申请哪一个。所以第一次保存会弹一次授权确认。 地址改动之后需要重新授权，点一次「保存」或「测试连接」即可。

模型收到的输入是从页面分析出来的设计简报（颜色、字号、间距、组件及其统计）， 不包含页面正文，也不包含你的 API Key 之外的任何凭据。

关于 LLM 提取的校验

数值部分由本地规则层负责，LLM 只补充语义。模型返回的内容如果包含阿拉伯数字， 或者引用了本次提取中不存在的 token，会被逐条丢弃并提示。 这样「数值与提取结果一致」是被结构保证的，不是靠提示词约束出来的。
