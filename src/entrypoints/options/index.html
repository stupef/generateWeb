AI 语义补全

不配置也能用。没有 Key 时插件照常产出一份完整的 DESIGN.md，只是文案由本地规则生成， 不会带上风格综述、颜色语义、组件描述和提示词示例。

关于存储

Key 存在本机的插件存储里（chrome.storage.local），不上传、不参与同步。 它没有加密，任何能读到这个浏览器配置文件目录的人都能看到它。不放心的话， 去服务商控制台单独建一把只用于这个插件的 Key，用完随时撤销。

网络权限按域名单独申请，只在你填了哪个地址时才申请哪一个。所以第一次保存会弹一次授权确认。 地址改动之后需要重新授权，点一次「保存」或「测试连接」即可。

模型收到的输入是从页面分析出来的设计简报（颜色、字号、间距、组件及其统计）， 不包含页面正文，也不包含你的 API Key 之外的任何凭据。

关于校验

模型回来的每一段文字都必须不含任何阿拉伯数字。数值由本地分析层负责写， 模型只补语义。不合规的字段会被逐条丢弃，界面上会告诉你丢了几处。 这样「补全后的数值与提取结果一致」是被结构保证的，而不是靠提示词祈祷的。
